Workflow automation engineering beyond the model response.

A production workflow begins—not ends—when a language model returns tokens. Reliable automation requires a formal definition of valid state, a zero-trust boundary around permitted effects, and independent proof that the intended output survived every transformation.

Verification & Scope Provenance · Architectural patterns implemented in Perihelion Loop (commit-pinned forensics as of 2026-11-18) and demonstrated via pure in-browser teaching reducers in Chapter IV.

Typed DAG Discipline ONE JOB · ONE INPUT · ONE OUTPUT · FAILS AS

Every node in Perihelion Loop declares explicit artifact edges, max-3 retry bounds, and deterministic joins.

Holdout & Council Gate Immutable Evaluator Separation

Workers cannot inspect or mutate holdout suites; contaminated patches trigger immediate git reset --hard.

Compile the workflow into executable contracts

Start with the input envelope, required output schema, and conservation laws that separate a valid result from a fluent guess. Partition the graph into deterministic code (parsers, exact math, branch merges), bounded model interpretation, and high-undo-cost human approval gates. Missing evidence must be a first-class machine-readable state rather than a void a model quietly bridges with fabrication.

Typed boundaries quarantine untrusted candidates until domain invariants hold. Structural JSON parsing clears only syntax; semantic validation verifies entity scope, conservation rules, and revision currency.

Persist state before recovery depends on it

Process crashes, rate-limit windows, and container restarts should never erase the meaning of completed or in-flight work. Persist the assignment revision, monotonic state counter, and immutable outbound intent before crossing any external wire.

A timeout after dispatch can mean the remote service committed the charge, webhook, or publication milliseconds before the caller's socket closed. Blindly retrying duplicates external side effects. Hold the step in UNCERTAIN, query the provider's transaction log or idempotency receipt, and reconcile before allowing further dispatch.

Keep untrusted data outside the authority boundary

Retrieved web pages, PDFs, emails, and model completions are data—never instructions. Tool adapters enforce narrow capability grants derived from authenticated workflow policy, never from text inside the prompt context.

In Perihelion Loop's hardened cloudroom.dev fabric, pre-spawn safety.ts verifies macAccessLevel === "off" and disconnects cloud GitHub before a VM starts, while transfer.ts verifies sorted SHA-256 manifests inside the VM and quarantines returned diffs locally against symlinks, path traversal, and .git spoofing.

Verify at the out-of-band artifact boundary

Evaluate the exact bytes the downstream operator or customer will consume, using an independent local runner the proposing agent cannot touch. Combine null-tested regressions (must fail on unchanged BASE, pass on HEAD), hidden holdout suites, and tool-less advisor diff audits.

These exact orchestration invariants power our live Texas mineral-interest title workflows on TitleDesk and Artificial Landman. See our landman title systems monograph and custom business software monograph for how these boundaries govern financial, legal-support, and multi-tenant SaaS builds.
